# Pseudostate wavefunctions for $l = 0$, $1$, and $2$

This directory contains the 10 radial pseudostate wavefunctions for 
$l = 0$, $1$, and $2$ by diagonalising the atomic hydrogen Hamiltonian with 
$N_{\rm max} = 10$ and $\zeta = 1.0$. 

These files are formatted in the following way. The first column 
is the electron radial grid and the remaining columns are the first, second, 
etc. pseudostate wavefunctions for that $l$.
